# AD Player for iPhone - what changed

Each version below is a release on GitHub (Releases, "v1.5.3" and so on). The newest is also "AD Player (latest)".
Install with Sideloadly.

## 1.5.3 - 2026-11-04
- The new square AD logo as the app icon.

## 1.5.2 - 2026-11-02
- When the PC can't be reached, it says why: mobile data turned off for the app, no internet, or the address not found.
- On the home Wi-Fi it uses the PC's home address by itself, and keeps the web address for away from home.
- Connect finishes straight away; the lists load after.

## 1.5.1 - 2026-11-02
- Saved places carry when they were saved, so the newest wins; places saved with no connection are sent when it's back.

## 1.5 - 2026-11-02
- Audiobook bookmarks (Audiobookshelf's own): add, list, jump to, rename, remove - with VoiceOver actions.

## 1.4.1 - 2026-11-01
- A web address is used just as typed (port 5021 is only added to the PC's own address).

## 1.4 - 2026-10-30
- Play together: Stop stops everyone, nobody is skipped ahead, it waits after a skip, and the audio is on the phone before it starts.
- Books are fetched a piece at a time, so they start quickly.

## 1.3 - 2026-10-29
- Headphone delay when playing together; adplayer://join links open the Join button.

## 1.2 - 2026-10-29
- Signing in, connecting straight to the PC on the home Wi-Fi, Play together, and staying up on phone networks.

## 1.1 - 2026-10-23
- Audiobooks from Audiobookshelf.

## 1.0 - 2026-10-20
- First version: play the audio description on the iPhone or a TV, made for VoiceOver.
